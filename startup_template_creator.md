## Startup Template Creator v1.0

*By Gruff Wright*

### Description

If you work in Blender across multiple disciplines --- modelling,
animation, compositing, sculpting, geometry nodes, VFX --- you've
probably wished Blender could *start up in the exact configuration you
need for the task at hand*.\
With **Startup Template Creator**, you can finally do that.

This add-on lets you **save, load, and manage multiple fully-custom
startup templates**, each with its own UI layout, file settings, and ---
uniquely --- **its own set of enabled/disabled add-ons**.\
Switching templates happens *immediately*, without restarting Blender.

That means one template can be ultra-minimal for video compositing,
while another can be loaded with mesh tools, sculpt extensions, or
geometry-node helpers. Blender loads *only* what that template requires,
freeing RAM and improving responsiveness.

------------------------------------------------------------------------

##  Key Features

### Save and Load Startup Templates

-   Store the entire current Blender configuration as a reusable
    template\
-   Load templates instantly without restarting Blender\
-   Organise template files in your chosen folder

### **Add-on Enable/Disable Persistence (Unique Feature!)**

-   Each template remembers **which installed add-ons should be enabled
    or disabled**\
-   When you load a template, Blender automatically switches add-ons to
    match it\
-   Perfect for task-specific setups:
    -   **Compositing Template:** All mesh tools, sculpt tools, 3D
        helpers *off*\
    -   **Modelling Template:** Compositor tools, render-heavy plugins
        *off*\
    -   **Lightweight Animation Template:** Texturing/UV plugins *off*\
-   Add-ons not required for the template stay **unloaded**, reducing
    RAM and startup overhead

### Optimised Workflows

-   Reduce clutter by hiding unused UI elements or heavy collections\
-   Keep different workspaces tailored to specific tasks\
-   Speed up your Blender environment by loading only what you need

### Clean, Accessible UI

-   Located in Blender's side panel (N-menu)\
-   Quick access to all templates and management tools\
-   Direct integration with user preferences for template storage paths

##  Benefits

-   **Massive performance savings:** Templates can disable expensive
    add-ons when not needed, keeping Blender lightweight and
    responsive.\
-   **Memory efficiency:** Unused plugins are not loaded into RAM for
    templates that don't need them.\
-   **Better focus:** Each template opens with the UI and tools relevant
    to the task.\
-   **No more manual toggling:** Forget searching through Preferences
    every time you switch workflows --- it's automatic.\
-   **Professional pipeline ready:** Perfect for artists who jump
    between distinct Blender tasks all day.

##  How to Install & Use

1.  Download the ZIP from this page.\
2.  Open **Blender 4.5.0 or later**.\
3.  Go to **Edit → Preferences**.\
4.  Click the small wing menu (top-right) → **Install From Disk...**\
5.  Select the ZIP file.\
6.  After installation:
    -   Search for "Startup Preset Manager" in the Add-ons tab.\
    -   Set your desired template storage folder.\
    -   Use the side panel (**N → Startup Presets**) to save or load
        templates.\
7.  Switching templates instantly loads your chosen add-ons, UI layout,
    and session configuration.
